DRIP (Dividend Reinvestment)
On = dividends buy more shares. Off = dividends paid as cash.
Use conservative blended yield
When on, ignores individual dividend-per-share and applies one yield % to the whole portfolio.
Choosing a blended yield for long-term projections

• 3.0% – 3.5% → Conservative dividend-growth style (SCHD / VYM heavy)
• 4.0% – 5.0% → Balanced mix (most common planning assumption)
• 5.5% – 6.5% → Higher current income (includes covered-call / high-yield positions)
• Above 7% → Aggressive. Possible today, but high yields often compress over 10+ years.

Tip: Start with 4.5% if unsure. Run once with real dividends and once with a conservative number to see the range.
How the basket system works:
1. Create baskets and give each a target % of every new dollar (must total 100%).
2. Add positions and assign each to a basket.
3. Inside each basket the position weights must also total 100%.
4. New money is split by basket % first, then by position weights inside the basket.
