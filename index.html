DRIP (Dividend Reinvestment)
On = dividends buy more shares of the same positions. Off = dividends paid as cash.
Use conservative blended yield
When on, ignores individual dividend-per-share numbers and applies one yield % to the whole portfolio.
Choosing a blended yield for long-term projections

• 3.0% – 3.5% → Conservative dividend-growth style (SCHD / VYM heavy)
• 4.0% – 5.0% → Balanced mix of growth + moderate income (most common planning assumption)
• 5.5% – 6.5% → Higher current income (includes meaningful covered-call or high-yield positions)
• Above 7% → Aggressive. Possible today with heavy JEPI/JEPQ/DIVO, but yields this high often compress over 10+ years.

Tip: Start with 4.5% if you’re unsure. Run the calculation twice — once with real current dividends and once with a more conservative blended number — to see the range of outcomes.
How the basket system works (important):

1. Create your baskets first and give each a target % of every new dollar. These must total exactly 100%.
2. Add positions and assign each one to a basket.
3. Inside each basket the position weights must also total exactly 100%.
4. When new money arrives (from Core or external), it is split by the basket percentages first, then by the position weights inside each basket.

This matches a real weighted-basket allocation system.
